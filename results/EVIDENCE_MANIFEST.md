## 3. Beginner-Friendly Reproduction Guide

This section is written specifically for students, laboratory instructors, and evaluators who wish to reproduce, inspect, or independently verify these experimental findings without requiring complex command-line programming knowledge.

### Step 1: Open the Application in Any Web Browser
1. Open Windows File Explorer and navigate to the project directory:
   `D:\7th Sem\PM\Mini project\MST-KMeans-Robustness-Analysis`
2. Double-click **`index.html`** to open the interactive dashboard in your default browser (Google Chrome, Microsoft Edge, Brave, or Mozilla Firefox).
   * *Alternative*: Right-click `index.html`, select **Open with**, and choose **Google Chrome** or **Microsoft Edge**.
   * *No server required*: The entire application is 100% browser-native JavaScript. You do not need to install Python, Node.js, npm, or run any local server.

---

### Step 2: Running Interactive Playground Demonstrations
1. At the top of the page, click the **Playground** tab in the navigation bar.
2. In the left-hand sidebar:
   * **Dataset**: Choose `Two Moons` or `Concentric Circles`.
   * **Sample Size**: Keep at `300`.
   * **Clusters (K)**: Select `2`.
   * **Noise ($\sigma$)**: Select `0.00` or slide to `0.05`.
   * **Outliers**: Try `0%`, then increase to `5%` or `10%`.
3. Click the green **Run Both Algorithms** button.
4. Observe the side-by-side clustering visualizations:
   * Notice how MST traces the curved shapes perfectly under clean conditions, while K-Means slices across them with straight linear boundaries.
   * Notice how adding outliers causes MST to create small isolated clusters around outlier points, leaving the main shapes lumped together.
5. In the **Metrics Comparison** table below the canvases, observe the real-time calculated **Adjusted Rand Index (ARI)** and **Execution Runtime (ms)**.

---

### Step 3: Running the Full Robustness Analysis Experiment
1. Click the **Robustness Analysis** tab in the navigation bar.
2. You will see controls for running parameter sweeps:
   * **Noise Sweep**: Tests $\sigma \in \{0.00, 0.05, 0.10, 0.20\}$.
   * **Outlier Sweep**: Tests contamination $\eta \in \{0\%, 5\%, 10\%, 20\%\}$.
   * **Seeds**: Uses random seeds $11, 22, 33$.
3. Click the **Run Robustness Experiment** button.
4. A progress indicator will show each trial executing. The browser runs 144 evaluations in less than a second.
5. When complete:
   * Interactive charts will display ARI vs Noise, ARI vs Outliers, and Degradation bar charts.
   * A summary table will display the Mean ARI, Standard Deviation, and Mean Degradation for each condition.

---

### Step 4: Running Performance Benchmarks
1. Click the **Performance Benchmarks** tab in the navigation bar.
2. Select the sample sizes: $N \in \{100, 200, 400, 600\}$.
3. Select **5 Repetitions per Size** on **Gaussian Blobs ($K=3$)**.
4. Click **Run Benchmark**.
5. The benchmark engine will perform warm-up runs, followed by 5 timed repetitions for each algorithm and sample size using `performance.now()`.
6. Inspect the resulting runtime plot:
   * K-Means remains very fast ($0.10\text{--}0.16\text{ ms}$).
   * Dense Prim's MST displays clear quadratic scaling ($0.14\text{ ms}$ at $N=100$ up to $1.70\text{ ms}$ at $N=600$).

---

### Step 5: Exporting Data and Figures from the Dashboard
The dashboard provides one-click export buttons in each section:
1. **Download Raw Results (CSV)**:
   * In the Robustness section, click **Export Raw Data (CSV)**.
   * In your browser, a file named `robustness_trials.csv` will automatically download.
2. **Download Summary Statistics (CSV)**:
   * Click **Export Summary Table (CSV)**.
   * A file named `robustness_summary.csv` will download.
3. **Export High-Resolution Charts (PNG)**:
   * Above each chart canvas, click **Export Chart (PNG)**.
   * The chart will download as a crisp PNG image (e.g., `ari_vs_noise.png`, `runtime_scaling.png`).

1. Open `results/summaries/robustness_summary.csv` in Microsoft Excel, Notepad, or VS Code.
2. Check the **Clean Baseline Rows**:
   * Under `dataset_family = blobs`, check that both K-Means and MST have `inlier_ari_mean = 1.000000`.
   * Under `dataset_family = moons`, check that MST has `inlier_ari_mean = 1.000000` and K-Means has `inlier_ari_mean = 0.194139`.
   * Under `dataset_family = circles`, check that MST has `inlier_ari_mean = 1.000000` and K-Means has `inlier_ari_mean = -0.001881`.

   * Under `dataset_family = moons` and `parameter_value = 5%`, check that MST `inlier_ari_mean = 0.000000` ($\Delta\text{ARI} = 1.000000$).
   * Under `dataset_family = blobs` and `parameter_value = 20%`, check that K-Means remains `1.000000` while MST drops to `0.379856`.
4. Check the **Benchmark Summary**:
   * Open `results/summaries/benchmark_summary.csv`.
   * Verify that at $N=600$, dense Prim's MST mean runtime is approximately $1.70\text{ ms}$, while K-Means is approximately $0.14\text{ ms}$ (a speedup of $\sim 12\times$ to $17\times$).
