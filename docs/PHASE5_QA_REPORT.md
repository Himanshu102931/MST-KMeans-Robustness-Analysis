## 4. Scientific Correctness Findings

### 4.1 K-Means (Lloyd's Algorithm with K-Means++ Initialization)
- **K-Means++ Initialization:** Correctly samples initial centers proportional to $D(x)^2 = \min_{j} ||x - \mu_j||^2$. Seeded Mulberry32 guarantees 100% reproducible initial centroids across runs.
- **Euclidean Metric:** $L_2$ norm squared and Euclidean distance functions are mathematically correct and free of precision leaks.
- **Inertia (Within-Cluster Sum of Squares, WCSS):** Verified formula $J = \sum_{k=1}^K \sum_{x \in C_k} ||x - \mu_k||^2$. Evaluates accurately at each step.
- **Convergence Guard:** Convergence halts when maximum centroid shift drops below tolerance ($1 \times 10^{-5}$) or max iterations ($100$) is reached.
- **Explorer Trace Equivalence:** Step-by-step explorer produces bitwise identical cluster assignments and identical final inertia compared to `KMeans.runKMeans()`.

### 4.2 Minimum Spanning Tree (Prim's Algorithm with Single-Linkage Cut)
- **Spanning Tree Invariant:** Generates exactly $N - 1$ Euclidean edges spanning all $N$ vertices on a connected complete Euclidean graph.
- **Analytical Triangle Test:** On vertices $(0,0), (3,0), (0,4)$, Prim selects edges of length $3$ and $4$, discarding the hypotenuse of length $5$. Total MST weight strictly equals $7.0000$.
- **Cut Invariant:** Removing the $K - 1$ longest edges deconstructs the spanning tree into exactly $K$ connected components.
- **Single-Linkage Vulnerability:** Successfully demonstrates vulnerability to noise chaining (peripheral outliers pulling single-linkage bridges across non-convex manifolds).

### 4.3 Adjusted Rand Index (Hubert & Arabie, 1985)
- **Contingency Matrix Construction:** Maps arbitrary cluster labels into a 2D contingency matrix $n_{ij}$.
- **Combinatorial Sums:** Correctly applies $\binom{n}{2} = \frac{n(n-1)}{2}$ across cell counts, row margins $a_i$, and column margins $b_j$.
- **Analytical Ground Truth:** Tested against analytical case $A = [0,0,1,1]$, $B = [0,1,0,1]$. Formula computes:
  $$\text{Index} = 0, \quad E[\text{Index}] = \frac{2 \times 2}{6} = \frac{2}{3}, \quad \max(\text{Index}) = \frac{2+2}{2} = 2$$
  $$\text{ARI} = \frac{0 - 2/3}{2 - 2/3} = \frac{-2/3}{4/3} = -0.500000$$
  Matches implementation to $1 \times 10^{-9}$.
- **Metric Symmetry & Permutation Invariance:** $\text{ARI}(A, B) = \text{ARI}(B, A)$, and permuting cluster IDs (e.g. $[0,0,1,1] \leftrightarrow [1,1,0,0]$) yields an exact $1.0$.
- **Separation of Inlier ARI:** Outlier points ($p.\text{isOutlier} = \text{true}$) are strictly excluded when computing Inlier ARI, allowing true manifold recovery measurement independent of peripheral noise.

## 6. Corrections Made

### 6.1 Defense Against CSV Formula Injection Without Corrupting Legitimate Numbers (DEF-01)
In [`js/export/export_manager.js`](file:///d:/7th%20Sem/PM/Mini%20project/MST-KMeans-Robustness-Analysis/js/export/export_manager.js):
```javascript
// Defense against CSV / Spreadsheet formula injection (CVE-2014-3524 / CWE-1236)
// If cell begins with =, +, -, @, \t, or \r, prefix with a single quote unless it is a valid finite number
const unsafeChars = ['=', '+', '-', '@', '\t', '\r'];
const trimmed = str.trim();
const isLegitNumber = trimmed !== '' && !isNaN(Number(trimmed)) && isFinite(Number(trimmed));

if (!isLegitNumber && unsafeChars.some(char => str.startsWith(char))) {
  str = "'" + str;
}
```
**Outcome:**
- Malicious formulas (`=1+1`, `+cmd|`, `-cmd|calc`, `@SUM(A1)`) are safely prepended with `'`.
- Legitimate negative numbers (`-1.452310`, `-0.500000`, `-123`) and positive numbers (`+42.0`) are preserved cleanly as raw numeric representations for seamless importing into Excel, Google Sheets, Python, and R.

### 6.2 Deterministic Tie-Breaking in MST Edge Cutting & Component Roots (DEF-02)
In [`js/algorithms/mst.js`](file:///d:/7th%20Sem/PM/Mini%20project/MST-KMeans-Robustness-Analysis/js/algorithms/mst.js):
- Edge sorting updated: `const sortedEdges = [...mstEdges].sort((a, b) => (b.weight - a.weight) || (a.id - b.id));`
- Component root sorting updated:
  ```javascript
  const sortedRoots = Array.from(rootCounts.keys()).sort((a, b) => {
    const diff = rootCounts.get(b) - rootCounts.get(a);
    return diff !== 0 ? diff : a - b;
  });
  ```
- Prim edge assembly in `computeEuclideanMST` aligned with `generateMSTTrace` so edge discovery order and edge IDs match bitwise.
**Outcome:** Guarantees 100% deterministic partitioning across repeated runs, even with lattice datasets or symmetrical edge ties.

### 6.3 Collision-Free Multi-Empty Cluster Reseeding in K-Means (DEF-03)

## 11. Performance Limitations and Asymptotic Complexity

1. **Theoretical Asymptotic Scaling:**
   - **K-Means (Lloyd's):** $O(N \cdot K \cdot I \cdot D)$, where $N$ is sample size, $K$ is clusters, $I$ is iterations ($\le 100$), and $D=2$. Empirically near-linear with respect to $N$.
   - **MST Clustering (Prim's dense implementation):** $O(N^2)$ due to dense all-pairs distance relaxation. Dominates execution time for $N > 1000$.
2. **Browser Single-Threaded Event Loop:**
   - Long-running sweeps yield to the event loop via `yieldToEventLoop()` (`setTimeout(resolve, 0)`), preventing UI freezes and allowing users to click the "Cancel" button.
3. **Timer Precision:**
   - Profiled via `performance.now()`, which modern browsers round to $\approx 5\,\mu\text{s}$ to mitigate Spectre-style timing side-channels. Repetitions (5+ trials) are averaged to ensure statistical significance.

## 13. Remaining Known Issues and Academic Considerations

1. **Memory Ceiling for Prim's Algorithm:**
   - Prim's implementation uses 1D typed arrays (`Float64Array`, `Int32Array`) rather than a full $N \times N$ matrix, keeping memory footprint at $O(N)$. Datasets up to $N = 2500$ run comfortably in browser memory.
2. **Non-Convex Chaining Trade-off:**
   - MST single-linkage clustering excels on concentric circles and interleaving moons ($\text{ARI} > 0.95$), but degrades rapidly under bridge noise. K-Means fails structurally on concentric circles ($\text{ARI} < 0.25$) but is more resistant to isolated random noise in convex clusters. This fundamental trade-off is the core academic thesis and is visually demonstrated across the dashboard.
